# 보상검색기

사고번호와 전화번호만 연결하면, 그 번호의 **문자**와 **통화녹음**을 폰 안에서 찾아 한 화면에 보여주는 안드로이드 앱입니다.
외근 보상직원이 개인폰으로 업무를 볼 때 "그 사람이랑 무슨 얘기 했더라?"를 바로 찾기 위한 개인 비서용 도구예요.

## 내려받기
**[최신 APK 받기](https://github.com/shinsak12-sketch/AI-Lecture/releases/download/bosang-search-latest/bosang-search.apk)**
(이 브랜치에 코드를 올리면 깃허브가 자동으로 새로 빌드합니다)

## 설치
1. 폰에서 위 링크로 APK를 받습니다.
2. 설치가 막히면: **설정 → 보안 및 개인정보 보호 → 자동 차단**을 잠시 끄고, 브라우저(또는 내 파일)에 **"출처를 알 수 없는 앱 설치"** 를 허용합니다.
3. 처음 열면 권한 4개(통화기록·문자·연락처·오디오)를 허용합니다.
   - 허용 창이 안 뜨거나 **"제한된 설정"** 이라고 나오면: 앱 정보 → 오른쪽 위 ⋮ → **제한된 설정 허용** → 권한에서 직접 허용
4. 새 버전은 지우지 않고 그대로 덮어 설치하면 됩니다. (등록한 내용 유지)

## 쓰는 법
- **등록**: [통화내역에서 등록] → 번호 고르기(여러 명 가능) → 사고번호(`26-` + 8자리) 입력 → 사람마다 관계 선택
  - 관계: 피보험자 · 계약자 · 피해자 · 배우자 · 부 · 모 · 자녀 · 형제 · 지인 · 정비소 · 병원 · 직접 입력
  - 관계는 사건마다 따로 저장돼요. 같은 사람이 다른 사건에선 다른 관계일 수 있으니까요.
- **검색**: 첫 화면에서 사고번호, 전화번호, 이름 아무거나
- **사건 화면**: 등록된 사람 전원의 문자 + 통화녹음이 시간순으로. 사람별·종류별로 골라 보기
- **사람 화면**: 그 사람의 문자 + 통화녹음 **전부**. 사고가 여러 건이어도 나누지 않고 한 번에
- 등록 안 된 번호도 검색창에 번호를 치면 바로 문자·녹음을 볼 수 있어요.

## 통화녹음 찾는 방식
갤럭시 통화녹음 파일 이름을 읽습니다.
- 저장 안 된 번호: `통화 녹음 01011112222_261002_174946`
- 저장된 연락처: `통화 녹음 홍길동_261002_174946`

연락처 이름으로 저장된 녹음은 이 순서로 번호를 찾아요.
1. **통화기록 시간 대조**: 그 시각(2분 이내)에 통화한 번호 → 가장 정확. 연락처 이름을 나중에 바꿔도 맞음
2. **연락처 이름**으로 번호 찾기
3. 같은 이름이 여러 명이면 **"확인 필요"** 표시

한 번 짝지어진 녹음은 기억해 두기 때문에, 나중에 통화기록이 지워져도 유지됩니다.

## 개인정보
- **인터넷 권한이 아예 없는 앱**이라, 읽은 내용을 폰 밖으로 보낼 수 없습니다.
- 문자·녹음 원본은 복사하지 않고 위치만 연결합니다. 앱이 직접 저장하는 건 사건-번호 연결과 관계뿐이에요.
- 구글 백업도 꺼 두었습니다.

## 알려진 한계
- **카카오톡**은 다른 앱이 읽을 수 없어서 보이지 않습니다.
- **채팅+(RCS)** 로 주고받은 메시지는 일반 문자 저장소에 없을 수 있어 안 보일 수 있습니다. (실제 폰에서 확인 필요)
- 통화녹음 파일 이름 형식이 위와 다르면 못 찾습니다.
